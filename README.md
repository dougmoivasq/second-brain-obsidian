# 🧠 Segundo Cerebro en Obsidian

Sistema personal de gestión del conocimiento basado en el método **PARA** (Proyectos, Áreas, Recursos, Archivo), construido en Obsidian con apoyo de Claude Code.

## ¿Qué problema resuelve?
La información (notas de reuniones, cursos, ideas, tareas) suele quedar dispersa. Este vault la organiza en un único lugar, enlazada y fácil de encontrar.

## Estructura
| Carpeta | Uso |
|---|---|
| `00-Inbox` | Todo lo nuevo entra aquí primero |
| `10-Proyectos` | Cosas con objetivo y fecha de fin |
| `20-Areas` | Responsabilidades continuas (trabajo, estudios, salud) |
| `30-Recursos` | Temas de interés y referencia |
| `40-Archivo` | Lo terminado o inactivo |
| `Diario` | Una nota por día |
| `Plantillas` | Plantillas reutilizables |

## Flujo de trabajo
1. **Capturar** → nota rápida en `00-Inbox`.
2. **Organizar** → moverla a Proyecto / Área / Recurso.
3. **Enlazar** → conectar ideas con `[[enlaces]]`.
4. **Revisar** → revisión semanal con `Plantillas/Revision semanal`.

## Plugins usados
- **Templates** (nativo): insertar plantillas.
- **Dataview** (comunidad): tablas automáticas, ej. ver `Inicio.md`.

## Cómo usarlo
1. Descarga o clona el repo.
2. Obsidian → *Open folder as vault* → selecciona la carpeta.
3. Instala Dataview desde *Community plugins*.

## Uso de IA
Estructura, plantillas y consultas Dataview diseñadas con **Claude Code**.
